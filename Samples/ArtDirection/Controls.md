# INARI 测试角色

独立入口类：`Runtime/InariStudyPlayer.gd`。没有修改工程里的 Shiro。

参数来自本机 INARI v0.2.1 的 `PlayerPhysicsProfile`、`PlayerCombatProfile`、
`PlayerAttackProfile`、`ShurikenObject` 和输入配置。读取原始资源，不执行原游戏。
`Original/INARI/controls.json` 保存数值及源文件 SHA-256；动画来自原始 Sprite 与
AnimationClip，另行保留 AnimatorController 的状态播放倍率。

| 操作 | 默认键位 |
| --- | --- |
| 移动 / 攀墙 | A、D / W、S |
| 跳跃、二段跳 / 下穿单向平台 | 空格 / S + 空格 |
| 沿角色朝向冲刺 | 左 Shift |
| 普攻、三段连击 / 重击 | 鼠标左键 / E |
| 向鼠标方向投掷 / 瞬移至苦无 | 鼠标右键 / Q |
| 重试 / 原图对照 / 隐藏说明 / 选关 | R / Tab / H / Esc |

手柄基本映射也来自原版：左摇杆移动，右摇杆瞄准，A 跳跃，LB 冲刺，RB 攻击，
RT 重击，LT 投掷及再次瞬移，右摇杆按下取消苦无。尚未完成实体手柄测试。

## 单位与已验证行为

场景转换比例为 16 像素 / Unity 单位。Godot 角色原点在脚底，原版原点位于碰撞盒中心；
只在角色边界转换位置与速度，配置中的数值保持原样。

- 跑速 21 单位/秒，即 336 像素/秒。原版加减速曲线实际均为常数 1，因此启动、松键停止即时生效。
- 跳跃撞到天花板单侧边缘时横移 1.2 单位并继续上升，整面天花板仍阻挡；纠偏与落点重叠搜索读取原版射线参数。
- 基础重力由最大跳高 3.1、到顶时间 0.22 推导；按住跳跃时乘 0.7，松开时截断上升速度。
- 空中第二跳速度为第一跳的 1.15 倍；土狼时间为 4 × 0.02 秒。
- 冲刺距离 11 单位，即 176 像素；曲线时长 11 × 0.02 秒，冷却 0.5 秒。
- 攀爬动画依据实际升降速度与接触切换；脚底侧无墙时使用原版墙角悬挂动画，顶住天花板时停止播放上爬。挂顶保持原版跳过普通移动的行为，身体和碰撞盒一起旋转，空格恢复直立并按原版下移半身高度。
- 苦无速度 95 单位/秒，无重力，最大距离 35 单位；必须命中后才能瞬移，恢复空中跳跃。
- 瞬移遇到重叠目标时，按原版方向顺序和步距搜索空位，再处理贴墙、挂顶或落地；地形目标忽略单向平台，敌人目标包含平台。
- 普通墙面瞬移耗体力 8；敌人瞬移耗体力 20、造成 50 点伤害，落点按原版地面边缘和墙面检测调整。
- 敌人附着的苦无跟随其移动、翻转；瞬移增加弱点层数，最多 3 层，5 秒后重置，下一次距离随层数增加。
- 飞行时提前按 Q 会保留 0.2 秒输入缓冲，等到命中再瞬移。目标死亡会清除附着的苦无。
- 重新投掷或取消时，旧苦无先变白再淡出（各 0.2 秒），期间继续运动，但已无法瞬移；投掷动作期间忽略取消。
- 工厂两处原版增益点首次补充 45 点体力，并给予 6 秒衰减移速加成；加成期间击杀可升级或刷新至 12 秒。触发点冷却 5 秒。
- 苦无按原版 ThrowShuriken 碰撞矩阵穿过单向平台，撞到 HardWall 会弹开消失；角色仍可站在平台上。
- 连击使用原始输入缓冲、位移曲线、命中帧及三个不同的原始动画。
- 工厂敌人可受击；每次挥刀对同一敌人结算一次伤害，击退与命中/击杀体力返还读取原版配置。
- 已导入 42 个角色动作，包含爬墙、落地、起跑、刹车、死亡、重生、方向投掷等。
- 从原版 FMOD 包提取 77 个音效样本，接入跳跃、二段跳、冲刺、连击、投掷、瞬移、攀墙、脚步、落地与破坏门。

`Tests/InariControllerProbe.gd` 在真实 Godot 物理步中发送输入。60 Hz 实测长按跳高
67.35 像素，短按 28.00 像素；速度、冲刺距离、连击和瞬移断言均通过。
`Tests/RouteProbe.gd` 另通过真实鼠标瞄准、右键投掷和 Q 输入，验证命中右上墙面、瞬移再蹬墙返回上层的路线。
`Tests/KunaiProbe.gd` 覆盖移动敌人附着、体力门槛、瞬移伤害、弱点超时、提前 Q 缓冲和死亡清理。
`Tests/EnemyProbe.gd` 验证普攻首段造成 40 点伤害、击退超过 20 像素、返还 5 点体力，
并覆盖独立受击闪光和弓手、步枪敌人的不同死亡表现。巡逻由 `Tests/PatrolProbe.gd` 单独覆盖；追击和主动攻击尚未接入。

## 当前边界

INARI 镜头由 `InariCameraRig.gd` 还原原版跟随：63° 视野、21.5 单位距离、角色高度 60%、
0.55 秒指数阻尼和 30% 外侧区域。瞬移暂停跟随 0.075 秒；R 重生立即恢复构图。
普攻命中、无弱点重击、苦无瞬移和瞬移击杀已接入原版震动波形与时间包络；默认使用原版 Full 强度。
弱点突进和受伤已接入对应镜头震动；机关震动及过场镜头切换尚未接入。

这是依据原版数据和动作逻辑移植的控制器。Godot 的接触解算与原版 Unity 自定义射线
碰撞器仍有差别。普通冲刺向下贴地和跳跃顶边纠偏已移植；向上越阶、完整天花板吸附及完整战斗反馈需要继续对照。
选中带弱点的敌人后，普通攻击键（手柄 RB）执行弱点突进：准备、选择性停顿、按层数命中与收招。
三档伤害为 125 / 250 / 500，执行期间免伤；原版落点修正、角色旋转、镜头震动和手柄震动已接入。
`Tests/WeakDashProbe.gd` 覆盖此操作链；三档原版色差后处理与 StackHit 事件混音已接入，并验证命中时机。
重攻击也按受击敌人的当前层数触发 StackHit 并清空弱点；部分粒子噪声与拉伸仍待移植。
空中推动右摇杆瞄准会按原版将登记对象减速至 0.3 倍，落地、攀爬或松开摇杆恢复；输入缓冲仍使用正常时间。
左摇杆也使用原版径向处理，处理后幅度超过 0.1 才移动，纵向分量超过 0.7 才触发上下操作；下推清除横向输入。
487 组原版 DLL 回调结果已用于核对左摇杆，包括 Mathf.Sign(0) 的原版特殊行为；数字化跑速不随摇杆幅度变化。
右摇杆使用原版径向死区与幅度重映射，减速判断使用处理后的输入；死区内轻微抖动不会反复延长瞄准显示。
手柄瞄准显示原版红色虚线与落点指示；5 单位以内的障碍收起线段，远处落点显示原始贴图颜色，锁定敌人时叠加黄色；倒影同步。
此版本切换键鼠不会主动恢复倍率，死亡、重生和切关会恢复。手柄地形辅助瞄准、完整碰撞类型切换与关卡机关仍需继续对照。
尚未宣称整体操作手感已达到逐帧一比一。
音效为原始样本，原版 FMOD 事件的混音、空间效果和随机音高尚未完整复刻。

```powershell
python Samples/ArtDirection/Tools/import_inari_controls.py 'G:/Misc/INARI_v0.2.1/Inari_Data'
python Samples/ArtDirection/Tools/import_inari.py 'G:/Misc/INARI_v0.2.1/Inari_Data'
```

ILSpy 导出的 `PlayerInputActions.cs` 以刷新输入映射；不提供时保留已提取的绑定。
